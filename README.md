# Keilverschluss Fräserkonfigurator

Konfigurator für den Keilverschluss (HM, FWP Entwicklungsstand): Fräser und Lamellenbreite einstellen, erreichbare Radien sehen und zusätzliche Fräser für einen Zielradius optimieren.

Online: https://vorhammer.github.io/keilverschluss/

Quellen in `src/`; `python3 src/build.py` erzeugt `index.html`.
